# 2L² | AI Software Development Website

2L²（ツーエルツー）の公式ホームページ。企業の業務に合わせたローカルLLM、独自RAG、専門業務向けAIソフトウェアの開発を紹介します。

## サイト構成

- `index.html`：ホーム、事業紹介、Local LLMの構成例、検討中の仮想テスト環境、会社概要、お問い合わせ
- `strengths.html`：権限制御・独自RAGの構成例、回答品質・運用設計の紹介
- `cases.html`：CTD（医薬品承認申請資料）作成支援ローカルLLMの開発実績、構想・検討中の取り組み
- `contact-form.html`：問い合わせ内容をメールアプリで確認して送信するフォーム
- `onboarding.html`：導入までの流れ
- `customer.html`、`privacy.html`、`security.html`：お客様向け情報と関連案内

## 開発・編集

- `content.js`：日本語・英語・タイ語の文章。全言語で同じ情報区分と技術的条件を維持します。
- `editorial.css`：共通の白・オフホワイト・ダークグレー・控えめなゴールドを使ったデザインの上書き。各ページで最後に読み込みます。
- `styles.css`、`journey.css` ほか：以前からのレイアウト規則・一部の機能を維持するためのベースCSS。
- `main.js`：ナビゲーション、多言語切替、業務紹介の開閉とスクロール時の収納。
- `info-pages.js`：技術資料・実績ページの翻訳と詳細開閉。
- `assets/brand-logo.png`：既存の公式ロゴ画像。セミコンダクター／GPU画像はホーム画面から削除済み。

静的HTML/CSS/JavaScriptのため、ビルドは必要ありません。ローカルHTTPサーバーで動作確認してください。

## 禁止事項・公開上の注意

1. **RAG性能に関する数値は再評価中**。旧過去の定量的な回答一致度の主張と関連グラフ・数値を再掲載しないでください。再評価結果が確認できるまで、架空の性能数値で代替しないでください。
2. **CTD開発事例**：外部AIへの研究データ送信を前提としないローカル構成による文書作成支援であり、全自動の申請資料完成や専門家の確認不要を意味しません。
3. **協業先の名称・プロジェクト情報**：協業先の医療文書作成の専門企業との取り組みは、相手方から対外公開の許諾を確認した後にのみ社名と案件詳細を掲載してください。許諾確認まではサイト上で匿名化しています。
4. **仮想テスト環境・担当者別AI支援**：構想と実装済みの機能を明確に区別してください。
5. お問い合わせフォームは `mailto:` によるメール本文作成です。サーバー送信機能はなく、送信は利用者のメールアプリで完了させます。
6. プライバシーポリシー・セキュリティ方針の内容が未確定のページについては、事実と異なる保証を記載しないでください。

## ブラウザテスト

```sh
npm install --no-save playwright
npx playwright install chromium
python3 -m http.server 8765 &
node tests/site-smoke.cjs
```

ブラウザテストでPC/タブレット/スマートフォン、3言語切替、各リンク、技術説明・CTD詳細の開閉、旧性能数値の非表示などを確認します。

## 公開

`website-improvements` に変更を蓄積し、CIの検証後に `website-release-20261025` へ反映します。`baseline` は変更しません。独自ドメインへ公開する前に、法的表示と相手先掲載許諾を確認してください。
